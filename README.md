# task app

## Features
- **create User**: Add a new user with username, password, roles, timezone and active status
- **Edit User**: Update a existing user's details
- **View User details**: click on the username to view detailed information about the user

## setup instructions



### Install Requirements
- pip install -r requirements.txt

### Run the parser file 
- python parser.py

### Start the backend server
- python app.py

### navigate to the task-app directory
- open a new terminal (or a new terminal window in vscode) 
- cd task-app

### install dependencies
- npm install

### Start vue.js development server
- npm run serve


## Set Up MongoDB if necessary
### ensure mongodb is installed
### Update mongodb connection on app.py if necessary
- client = MongoClient("mongodb://127.0.0.1:27017")
